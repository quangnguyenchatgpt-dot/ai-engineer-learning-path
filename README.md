# AI Engineer Learning Path — ENG/VN

**48 weeks · 3 sessions/week · 120 minutes/session · 144 sessions · 288 guided hours.**

Entry: Python developer; Balanced AI Engineer track. Numbered sessions without fixed weekdays.

## Curriculum
1. Python Engineering Bridge — S001–S012
2. Mathematics for AI — S013–S027
3. Data Science & Machine Learning — S028–S048
4. Deep Learning & PyTorch — S049–S069
5. NLP, Transformers & LLMs — S070–S087
6. RAG & AI Agents — S088–S108
7. MLOps, LLMOps & Deployment — S109–S123
8. Advanced AI & Safety — S124–S132
9. Capstone & Portfolio — S133–S144

## Course policy
Bilingual VN/EN instruction. Each session includes a lab, assessment, review and artifacts. A passing score is at least 80/100 with required acceptance tests. See [AGENTS.md](AGENTS.md), [resources](resources/sources.md) and [progress](learning/progress.json).

This independent curriculum draws on public university and technical learning resources. It is **not** an MIT, Stanford, CMU or Berkeley certification.

Initial repository commit contains core configuration and learning guidance. Full 144-session catalog, lab catalog and dashboard are packaged separately for upload.
