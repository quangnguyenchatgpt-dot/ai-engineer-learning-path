# S001 — Diagnostic Python + AI environment

**Thời lượng:** 120 phút · **Lab:** LAB-001 · **Track:** Balanced AI Engineer

## Outcomes / Mục tiêu
- Kiểm tra được Python 3.9+ và tạo isolated virtual environment.
- Explain dependency management, NumPy arrays and reproducible execution.
- Xác định được năng lực Python hiện tại để điều chỉnh các buổi tiếp theo.

## Agenda
10m prior skills diagnostic · 20m environment concepts · 70m lab · 20m assessment.

## Lab LAB-001
1. Create a Python virtual environment and document versions.
2. Install NumPy and pytest.
3. Implement functions computing mean, standard deviation and normalized values from an input list.
4. Handle empty lists and constant-value inputs safely.
5. Include at least 3 pytest tests.
6. Provide README, commands, outputs and a short bilingual explanation.

## Acceptance
Reproducible setup; required functions pass validated tests; edge cases handled; concept checks answered; >=80/100.
