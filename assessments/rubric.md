# Standard Assessment Rubric / Thang điểm đánh giá

| Dimension | Points | What to check |
|---|---:|---|
| Functional correctness | 35 | Requirements and expected outputs |
| Code quality | 20 | Design, naming, readability and maintainability |
| Tests and edge cases | 20 | Automated assertions, failures, boundary cases |
| Conceptual understanding | 15 | Student can explain why it works, EN/VN |
| Documentation | 10 | Setup, usage, reproducibility and reflection |
| **Total** | **100** | |

## Gate
Passing >=80/100 **and** mandatory acceptance tests. Scores 60–79 require remediation; below 60 repeat prerequisites. Do not fabricate test results or infer completion from the presence of a file.

## Assessments
- Each session: lab and concept check.
- Every third session: weekly checkpoint.
- End of each phase: milestone and review.
- Final phase: capstone evaluation and portfolio presentation.
